# Paper/report catalogue

Audit date: **2026-09-11**. **33 distinct reports accounted for: 31 arXiv identifiers
and 2 official repository-linked reports.** Core implements four mechanism groups;
it does not implement all papers. Later rows are explicit plans, not completed
analytical studies or models. One row per report; arXiv revisions and checkpoints
are deduplicated. Dates below are the latest observed submission in the retrieved
arXiv history, not necessarily product launch dates. Canonical metadata and full
revision histories: [source-metadata.json](docs/source-metadata.json).

Discovery covered the seed, official news, GitHub organization/index, HF organization
page, linked reports, and affiliation searches. See [discovery audit](docs/discovery.md)
for source hashes, inspected reference commits, additions, inconsistencies, blocked
pagination/PDFs, and search gaps. This is an auditable bounded discovery pass, **not
a certified exhaustive bibliography of every employee's publications**.

Coverage labels distinguish mechanism implementation, toy analogue, training-recipe
subset, analytical study and source-blocked. All later labs require reading full
methods/current reference code before implementation. Existing shared code alone
does not complete the newer paper's delta. Every omitted training corpus, model
asset, scale result and hardware measurement remains unreplicated.
