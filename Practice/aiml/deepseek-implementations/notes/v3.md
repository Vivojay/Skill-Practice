# V3 — sequential multi-token prediction

Source: [2412.19437v2](https://arxiv.org/html/2412.19437v2), section 2.2,
equations 21–25. The official inference reference was inspected, but it does not
contain the MTP training implementation. The disclosed report supplies the method.

## Equation to code

`MTPModel.base` returns h_i^0:[B,T,D]. For depth 1, concatenate RMSNorm(h_i^0) with
RMSNorm(Emb(t_{i+1})), project [2D]->[D], then apply a separate causal Transformer
block. `combine` and `next_block` implement equations 21–22. The **same** embedding
and output head are used at both depths; this does not mean embedding/output
weights themselves are tied. A common final RMSNorm is a stated tiny-backbone
convention. The MTP block cannot see tokens beyond t_{i+1} when predicting t_{i+2}.

`supervision` makes depth-0 targets tokens[:,1:] and depth-1 targets tokens[:,2:].
`prediction_losses` excludes invalid trailing/right-padded targets. Both sums use
the valid NTP-prediction count as denominator, retaining the report's 1/T convention
at finite sequence boundaries rather than renormalizing the shorter MTP loss.
Total loss is L_NTP + 0.3 L_MTP with one additional depth.

## Scope and evidence

Run `python -m pytest tests/test_mtp.py` and `python -m examples.mtp --variant ntp`,
then the same with `--variant mtp`. Shared weights and task RNG start identically.
Each consumes 30,720 backbone token positions; MTP adds 28,800 block positions.
All 64 modular-progression combinations are evaluated. They may occur in training;
these are distribution-fit results, not held-out compositional generalization.
Accuracy excludes the initial unknown-stride prediction; loss includes it.

[NTP result](../results/mtp-ntp.json), [MTP result](../results/mtp-mtp.json).
MTP slightly reduced NTP cross-entropy but slightly reduced predictable-token
accuracy, while roughly doubling measured training step time. Single paired seed.

Implemented: one sequential depth, shared parameters, shift/mask tests, causal and
gradient tests, overfit and paired training. Simplified: dense width-32 single-layer
backbone with learned positions. Omitted: V3 MLA/MoE integration, original corpora,
FP8, multiple MTP depths and speculative decoding. No draft/verify/cache-rollback
demonstration or stochastic-sampling equivalence claim is made in core.

## Limitations and further experiments

Inferred limitation: auxiliary gradients can conflict with the next-token objective
and add substantial work. Proposed future change: a fixed annealing schedule for
MTP weight, giving the main objective priority late in training. Cost: schedule
choice and a matched-budget training comparison. Failure: removing the auxiliary
signal loses its representation benefit. Falsify using held-out next-token loss
and measured compute against constant weight, with fixed trial budget. The V3
training recipe already changes MTP weighting, so this would be an ablation;
**not implemented** as an extra extension here.
