# V2 — multi-head latent attention

Source: [2405.04434v5](https://arxiv.org/html/2405.04434v5), sections 2.1.2–2.1.3,
equations 9–19. Shared absorption algebra checked against pinned official V3
`inference/model.py`; [license and attribution](../THIRD_PARTY.md).

## Equation to code

`MLA._project` maps X:[B,T,D] to normalized cKV:[B,T,C] and cQ:[B,T,Q]. Up-projected
content queries are [B,T,H,Dc]. Separate query and shared-key projections carry
RoPE: qR:[B,T,H,R], kR:[B,T,R]. `rope` rotates adjacent coordinate pairs. Low-rank
normalization follows the inspected reference; no normalization lies between an
up-projection and its absorbed linear contraction.

`_attention(expanded=True)` forms K=[UK cKV; kR] and V=UV cKV per head. The explicit
causal softmax uses scale 1/sqrt(Dc+R). The compressed path instead computes
qC^T UK cKV + qR^T kR. After softmax A it forms A cKV and applies the composed
output map WO_h UV_h. These are linear rearrangements with identical weights;
the position-dependent RoPE terms stay separate.

`decode` returns an explicit detached cache and masked logits. Cache carries its
starting offset; continuation must be contiguous. Persistent cache storage is
B*S*(C+R)*element_size versus B*S*H*(Dc+R+Dv)*element_size for the actual expanded
implementation. `Cache.nbytes` counts distinct backing allocations, including
positional keys. It excludes transient attention matrices, weights and Python
object overhead; process memory is reported separately.

## Scope and evidence

`python -m pytest tests/test_mla.py`: float64 scalar head/key oracle, 2e-12
equivalence tolerance, prefixes/offsets, noncontiguous-cache rejection, RoPE,
causality and numerical gradcheck. `python -m examples.mla`: overfit previous-vector
targets on a fixed [2,8,32] batch, then benchmark prefill [2,16,32] and one-token
continuation of length-15 prefixes. Five warmups, 25 measurements each, medians and
IQRs. CPU runs need no device synchronization. [Saved result](../results/mla.json).

Simplified: one layer, float32 training, ordinary RoPE, dense attention, dynamically
concatenated caches, absorption recomputed per call. Omitted: YaRN, quantization,
fused kernels, paged caches and V2 language-model training. No benchmark comparison
with published kernels; no arbitrary pretrained-MHA equivalence or speed guarantee.
The local smaller cache was slower on this workload.

## Limitations and further experiments

Inferred limitation: a fixed shared KV rank can bottleneck token information even
when attention logits are accurate. Proposed future study: allocate a fixed cache
budget differently between content rank and RoPE dimensions, retraining each model.
Costs: several training runs and changed projection work. Failure: less positional
capacity degrades longer-prefix tasks. Falsify using held-out loss at equal measured
cache bytes, not cache size alone. The paper studies attention/cache tradeoffs;
rank-allocation novelty is unassessed. This modification is **not implemented**.
